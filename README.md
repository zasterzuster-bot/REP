# AdMarket — биржа прямой рекламы

Сайт, где владельцы сайтов добавляют свои площадки для прямой рекламы:
описание, рейтинги (TLD-AI, Majestic TF, Ahrefs DR, Moz DA, PR(Google), xRank, CyberMD),
цена за 1000 показов (CPM), трафик, регион, языки, теги и контакты.

## Запуск
```bash
python3 app.py        # http://localhost:8000 (порт задаётся переменной PORT)
```

## Возможности
- Каталог сайтов с поиском, фильтром по категориям и сортировкой (цена/трафик)
- Форма добавления сайта с полями рейтингов и цены за показы
- Удаление объявлений, статистика (кол-во сайтов, суммарный трафик, средний CPM)
- SQLite-хранилище (`sites.db`), демо-данные при первом запуске
- Без внешних зависимостей — только стандартная библиотека Python
